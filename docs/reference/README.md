# Arsip Referensi

Folder ini menyimpan proposal, roadmap, questionnaire lama, dan specification history. Isinya dipertahankan untuk konteks Git/project, tetapi dapat bertentangan dengan code dan keputusan pasca-game-jam.

Untuk implementasi gunakan, secara berurutan:

1. [`../gdd_en.md`](../gdd_en.md);
2. [`../fondasi_teknis_godot.md`](../fondasi_teknis_godot.md);
3. [`../implementation/`](../implementation/);
4. [`../panduan_programming.md`](../panduan_programming.md) dan authoring guide terkait.

[`technical_history/`](technical_history/) berisi programmer specs dan handoff yang sudah diserap ke live contract. Jangan menyalin pseudocode, state, angka, atau path dari arsip tanpa memeriksa source saat ini dan mendapat keputusan baru.
