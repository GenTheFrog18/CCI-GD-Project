# Arsip Referensi

File dalam folder ini adalah dokumen desain sebelum keputusan fondasi 7 Agustus 2026. Isinya dipertahankan untuk konteks dan dapat mengandung aturan lama—terutama mengenai Multitool, universal throw action, Rattlepod, projectile enemy, dan final gatekeeper.

Untuk implementasi, gunakan `../fondasi_teknis_godot.md` dan `../panduan_programming.md`. Jangan menyalin kontrak teknis dari arsip ini tanpa memeriksa dokumen terbaru.
