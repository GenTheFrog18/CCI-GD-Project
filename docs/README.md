# Urutan Dokumen

Gunakan urutan berikut ketika dokumen bertentangan:

1. `fondasi_teknis_godot.md` — keputusan gameplay/arsitektur yang sudah dikunci.
2. `panduan_programming.md` — aturan implementasi dan review code.
3. `pertanyaan_klarifikasi_fondasi.md` — decision history yang sudah dijawab.
4. `reference/` — arsip roadmap/spec lama; tidak mengalahkan keputusan terbaru.

Jangan memperbaiki konflik dengan memilih dokumen yang paling sesuai dengan code yang sedang dibuat. Laporkan konflik kepada lead dan perbarui sumber kebenaran terlebih dahulu.
